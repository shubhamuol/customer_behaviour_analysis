# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Overview

This project focuses on analysing customer shopping behaviour to identify purchasing patterns, product preferences, customer segments, discount usage and subscription trends.

The project follows an end-to-end data analytics workflow, starting with data loading and Exploratory Data Analysis (EDA) in Python, followed by data cleaning, SQL-based business analysis using PostgreSQL, and interactive dashboard development in Power BI.

A final project report and presentation are also included to communicate the findings and business recommendations.

## 🎯 Project Objectives

- Understand customer purchasing behaviour and spending patterns.
- Analyse revenue across gender and age groups.
- Identify popular products and highly rated products.
- Evaluate discount usage and shipping preferences.
- Compare subscribers and non-subscribers.
- Segment customers based on previous purchases.
- Build an interactive Power BI dashboard.
- Present actionable business insights.

## 📂 Dataset

The project uses a customer shopping behaviour dataset containing **3,900 records and 18 original columns**.

Key attributes include:

| Category | Columns |
|---|---|
| Customer Information | Customer ID, Age, Gender, Location |
| Product Information | Item Purchased, Category, Size, Color, Season |
| Purchase Details | Purchase Amount, Previous Purchases, Frequency of Purchases |
| Customer Experience | Review Rating, Shipping Type |
| Marketing | Discount Applied, Promo Code Used |
| Subscription | Subscription Status |
| Payment | Payment Method |

## 🔄 Project Workflow

### 1. Data Loading
- Imported the dataset using Pandas.
- Examined the dataset structure, dimensions and data types.
- Reviewed sample records and descriptive statistics.

### 2. Exploratory Data Analysis (EDA)
- Analysed numerical and categorical variables.
- Identified missing values and potential data-quality issues.
- Explored customer demographics and purchasing patterns.
- Examined product categories, purchase amounts and ratings.

### 3. Data Cleaning & Preparation
- Standardised column names.
- Handled missing review ratings using category-wise median imputation.
- Created customer age groups using `pandas.qcut()`.
- Converted purchase frequency categories into approximate day intervals.
- Checked and removed redundant columns.
- Prepared the cleaned dataset for SQL analysis.

### 4. SQL Business Analysis

Loaded the cleaned dataset into PostgreSQL and developed SQL queries to answer ten business questions:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used a discount but still spent at least the average purchase amount?
3. Which are the top five products with the highest average review rating?
4. How do average purchase amounts compare between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which five products have the highest percentage of purchases with discounts applied?
7. How many customers belong to New, Returning and Loyal segments?
8. What are the top three most purchased products within each category?
9. Are repeat buyers (more than five previous purchases) also likely to subscribe?
10. What is the revenue contribution of each age group?

**SQL concepts used:**
- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- Subqueries
- CASE WHEN statements
- Common Table Expressions (CTEs)
- Window functions
- ROW_NUMBER()
- Conditional aggregation

## 🚀 How to Run

### Prerequisites

Install or have access to:

- Python 3.x
- Jupyter Notebook
- PostgreSQL
- Microsoft Power BI Desktop

### Step 1: Clone the repository

```bash
git clone https://github.com/shubhamuol/customer-shopping-behaviour-analysis.git
```

### Step 2: Install Python libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

### Step 3: Run the Jupyter Notebook

Open the notebook:

```bash
jupyter notebook
```

Run the cells sequentially to load, explore, clean and prepare the dataset.

### Step 4: Set up PostgreSQL

- Create a PostgreSQL database.
- Import the cleaned dataset into the database.
- Open the SQL script in pgAdmin.
- Execute the queries to reproduce the business analysis.

Update database connection credentials locally. Do not upload passwords or sensitive credentials to GitHub.

### Step 5: Open the Power BI Dashboard

Open the `.pbix` file using Power BI Desktop.

If necessary, update the data source connection and refresh the dataset.

### Step 6: Review the Project Report & Presentation

Open the PDF report and presentation included in the repository to explore the methodology, findings and recommendations.
